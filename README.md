# Numerical Analysis using Python

A collection of **Numerical Analysis problems and methods implemented using Python**.
This repository contains numerical techniques commonly used in engineering and mathematical problem-solving.

## 📚 Topics Covered

### 1. Equation of One Variable

Methods for finding the roots of nonlinear equations.

* Bisection Method
* False Position Method
* Newton-Raphson Method
* Secant Method

### 2. Roots of Polynomial

Methods for finding the roots of polynomial equations using Python.

### 3. System of Linear Algebraic Equations

Numerical methods for solving systems of simultaneous linear equations.

* Gauss Elimination
* Gauss-Jordan Elimination
* Jacobi Iteration
* Gauss-Seidel Method

### 4. Numerical Solution of ODEs

Numerical methods for solving ordinary differential equations.

* Euler's Method
* Euler's Method with different step sizes

## 🛠️ Tools & Libraries

* Python
* NumPy
* Matplotlib
* Jupyter Notebook


## 🎯 Purpose

The purpose of this repository is to learn, implement, and practice numerical analysis techniques using Python, with applications to mathematical and engineering problems.
